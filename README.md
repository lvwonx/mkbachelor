# MKBachelor

Web application developed as part of a bachelor's thesis.

## Project structure

The repository contains a backup of the server environment required to run the application:

- `var/www/mkbachelor.com/` — application source code and web resources
- `etc/apache2/` — Apache configuration
- `etc/systemd/` — systemd configuration
- `etc/hosts` — hosts configuration
- `etc/passwd` — local user accounts
- `etc/group` — local user groups
- `database/db.sql` — PostgreSQL database dump

## Technologies

- Python
- Flask
- PostgreSQL
- Apache HTTP Server
- JavaScript
- HTML
- CSS

## Purpose

This repository is used for version control and backup of the web application and its server configuration.
